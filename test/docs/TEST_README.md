# API 測試文件說明

## 文件結構

### 1. API_TEST_GUIDE.md
完整的 API 測試指南，包含：
- 所有 API 端點的詳細測試方法
- 完整的 curl 命令範例
- 錯誤處理測試
- 數據驗證測試
- 性能測試腳本
- 故障排除指南

### 2. test_api.sh
快速測試腳本，提供：
- 自動化測試所有 API 端點
- 彩色輸出和錯誤處理
- 性能測試
- 中文內容測試
- JSONB 字段測試

## 使用方法

### 快速測試
```bash
# 啟動服務器
go run ./cmd/server

# 在另一個終端運行測試
./test_api.sh
```

### 詳細測試
```bash
# 查看完整測試指南
cat API_TEST_GUIDE.md

# 手動執行特定測試
curl -sS http://localhost:8080/health | jq .
```

## 注意事項

1. **服務器狀態**: 確保服務器在 8080 端口運行
2. **數據庫連接**: 確保 PostgreSQL 數據庫可用
3. **依賴工具**: 需要安裝 `curl` 和 `jq`
4. **權限設置**: 確保 `test_api.sh` 有執行權限

## 故障排除

### 常見問題
1. **服務器未運行**: 先啟動 `go run ./cmd/server`
2. **端口被占用**: 檢查 8080 端口是否被其他程序使用
3. **數據庫連接失敗**: 檢查 PostgreSQL 服務狀態
4. **權限錯誤**: 運行 `chmod +x test_api.sh`

### 日誌查看
```bash
# 查看服務器日誌
go run ./cmd/server 2>&1 | tee server.log

# 查看測試輸出
./test_api.sh 2>&1 | tee test.log
```

## 自定義測試

### 修改測試數據
編輯 `test_api.sh` 中的測試數據，例如：
```bash
# 修改公司名稱
"name": "我的測試公司"
```

### 添加新測試
在 `test_api.sh` 中添加新的測試函數：
```bash
test_new_feature() {
    echo -e "${YELLOW}測試新功能...${NC}"
    test_api "新功能測試" "POST" "$API_BASE/new-endpoint" '{"data": "test"}'
}
```
