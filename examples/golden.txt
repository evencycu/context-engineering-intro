Golden Sample for Teams Chat Setup and App Installation

Overview
- This golden sample consolidates the essential, verified steps and values from sample/main.go and sample/testdata.txt.
- Use it to quickly seed a Teams group chat and install your Teams app into that chat.

Prerequisites
- A valid Microsoft Graph access token with Chat.ReadWrite and AppCatalog.ReadWrite.All permissions.
- Your Teams App (Teams App ID) published/visible in your tenant app catalog.

Variables
- TEAMS_APP_ID: 35299c15-b84d-479f-badc-209a98c504d3
- CHAT_ID (decoded): 19:0a608973d8484d30981e68f1ed45a5c8@thread.v2
- CHAT_ID (url-encoded): 19%3A0a608973d8484d30981e68f1ed45a5c8%40thread.v2
- TOKEN: <paste your Graph API bearer token here>

Step 1) Create a Teams group chat (example)
curl -X POST https://graph.microsoft.com/v1.0/chats \
  -H "Authorization: Bearer $TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "chatType": "group",
    "topic": "客服協助群組A1",
    "members": [
      {
        "@odata.type":"#microsoft.graph.aadUserConversationMember",
        "roles":["owner"],
        "user@odata.bind":"https://graph.microsoft.com/v1.0/users/bd5ab633-3f6f-48ad-be04-e144480da48f"
      },
      {
        "@odata.type":"#microsoft.graph.aadUserConversationMember",
        "roles":["owner"],
        "user@odata.bind":"https://graph.microsoft.com/v1.0/users/76bdf4ee-c942-4c75-8fdf-608909c51abb"
      }
    ]
  }'

# Example response contains the created chat id (decoded):
#   19:0a608973d8484d30981e68f1ed45a5c8@thread.v2

Step 2) Install your Teams app into the chat
curl -X POST "https://graph.microsoft.com/v1.0/chats/19%3A0a608973d8484d30981e68f1ed45a5c8%40thread.v2/installedApps" \
  -H "Authorization: Bearer $TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "teamsApp@odata.bind": "https://graph.microsoft.com/v1.0/appCatalogs/teamsApps/35299c15-b84d-479f-badc-209a98c504d3",
    "consentedPermissionSet": {"resourceSpecificPermissions": [
      {"permissionValue":"ChatMessage.Read.Chat","permissionType":"application"},
      {"permissionValue":"ChannelMessage.Read.Group","permissionType":"application"}
    ]}
  }'

Notes
- Use the url-encoded CHAT_ID in Graph URLs; use the decoded form when displaying.
- The sample/main.go demonstrates endpoints for /api/messages and /api/proactive and how to send proactive messages once you have a valid Connector token.
- Ensure appID/appSecret in sample/main.go are set to your bot’s Microsoft App credentials if you test that server locally.
