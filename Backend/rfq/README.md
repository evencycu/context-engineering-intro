## ❓ 常見問題

### Q1: 需要實作前端 UI 嗎？

**A**: 不需要。本專案僅開發後端 API Server，不包含前端 UI。

### Q2: Teams Bot 需要廠商申請嗎？

**A**: 不需要。Microsoft Teams Bot 的申請與註冊由本公司負責，廠商僅需整合 Bot Framework API。

### Q3: 雲端基礎設施由誰提供？

**A**: 由本公司提供。廠商需提供 Docker 映像和 Kubernetes 配置檔案，但不需負擔雲端費用。

### Q4: P1 和 P2 功能可以不實作嗎？

**A**: 
- **P0**: 必須實作，否則系統無法運作
- **P1**: 強烈建議實作，會影響評分
- **P2**: 可選實作，不影響決標

### Q5: 測試覆蓋率一定要達到 70% 嗎？

**A**: 是的，這是驗收標準之一。建議在開發過程中持續維護測試覆蓋率。

### Q6: 可以使用第三方套件嗎？

**A**: 可以。但必須使用 Go Module 管理依賴，並確保所有套件都是開源且授權允許商業使用。

### Q7: 需要支援多語系嗎？

**A**: 不需要。系統主要使用繁體中文，API 文件使用英文即可。

### Q8: 保固期後的維護費用如何計算？

**A**: 請在報價時另行提供維護方案（月費或年費）和功能擴充的人日報價。
