## 🚀 快速開始（推薦方法）

### 方法 1: 使用 Marp CLI（最簡單） ⭐

#### 安裝 Marp CLI

```bash
# 使用 npm 安裝
npm install -g @marp-team/marp-cli

# 或使用 Homebrew (macOS)
brew install marp-cli
```

#### 轉換為 PDF

```bash
cd rfq
marp RFQ簡報.md -o RFQ簡報.pdf
```

#### 轉換為 HTML（可互動）

```bash
marp RFQ簡報.md -o RFQ簡報.html
```

#### 轉換為 PPTX（PowerPoint）

```bash
marp RFQ簡報.md -o RFQ簡報.pptx
```

---

### 方法 2: 使用 Marp for VS Code（視覺化） ⭐⭐⭐

#### 安裝擴充套件

1. 開啟 VS Code
2. 搜尋並安裝 **Marp for VS Code** 擴充套件
3. 開啟 `RFQ簡報.md`
4. 點擊右上角的預覽按鈕
5. 使用匯出功能

#### 匯出選項

- **PDF**: 適合列印與分享
- **HTML**: 適合網頁展示
- **PPTX**: 適合進一步編輯

---

### 方法 3: 線上轉換（無需安裝） ⭐⭐

#### 使用 Marp Web

1. 前往 https://web.marp.app/
2. 貼上 `RFQ簡報.md` 內容
3. 即時預覽
4. 匯出為 PDF/HTML/PPTX

#### 優點
- 無需安裝任何工具
- 即時預覽效果
- 支援多種匯出格式

## 🎨 進階自訂

### 修改主題

編輯 `RFQ簡報.md` 檔案頭部：

```yaml
---
marp: true
theme: default  # 可改為 gaia, uncover
paginate: true
header: 'RFQ-2025-TEAMS-NOTIFY-001'
footer: '© 2025 [公司名稱]'
size: 16:9  # 或 4:3
style: |
  section {
    background-color: #f5f5f5;  # 背景色
    font-size: 28px;            # 字體大小
  }
  h1 {
    color: #6264A7;             # 標題顏色
  }
---
```

### 可用主題

- **default**: 預設主題（簡潔）
- **gaia**: 現代風格
- **uncover**: 全螢幕風格

### 插入圖片

```markdown
![width:600px](path/to/image.png)
![bg right](path/to/background.jpg)
```

## 🔧 故障排除

### 問題 1: Marp CLI 安裝失敗

**解決方案**:
```bash
# 確認 Node.js 已安裝
node --version

# 如未安裝，先安裝 Node.js
brew install node  # macOS
# 或從 https://nodejs.org/ 下載

# 重新安裝 Marp CLI
npm install -g @marp-team/marp-cli
```

### 問題 2: 中文顯示異常

**解決方案**: 確保系統已安裝中文字體

```bash
# macOS: 系統預設已有中文字體
# Linux: 安裝字體
sudo apt-get install fonts-noto-cjk
```

### 問題 3: PDF 匯出失敗

**解決方案**: 需要安裝 Chrome 或 Chromium

```bash
# macOS
brew install --cask google-chrome

# Linux
sudo apt-get install chromium-browser
```

## 📱 輸出格式比較

| 格式 | 優點 | 缺點 | 適用場景 |
|------|------|------|---------|
| **PDF** | 跨平台、易分享、格式固定 | 無法編輯、檔案較大 | 正式簡報、列印 |
| **HTML** | 互動性強、檔案小、可嵌入網頁 | 需瀏覽器、排版可能變動 | 線上展示、網站嵌入 |
| **PPTX** | 可編輯、相容 PowerPoint | 樣式可能跑掉 | 需進一步編輯 |

## 💡 最佳實踐

### 簡報製作建議

1. **保持簡潔**: 每頁不超過 50 字
2. **視覺化**: 使用圖表、流程圖
3. **對比色**: 使用高對比度配色
4. **字體大小**: 最小 24px
5. **一頁一重點**: 避免資訊過載

### 簡報演講建議

1. **時間控制**: 每頁 2-3 分鐘
2. **互動**: 適時詢問聽眾
3. **眼神交流**: 不要只看投影片
4. **備份**: 準備 PDF 和 PPTX 兩個版本
5. **練習**: 至少練習 3 次

## 🚀 快速指令參考

```bash
# 基本轉換
marp RFQ簡報.md                    # 預設 HTML
marp RFQ簡報.md -o output.pdf      # PDF
marp RFQ簡報.md -o output.html     # HTML
marp RFQ簡報.md -o output.pptx     # PPTX

# 進階選項
marp RFQ簡報.md --pdf --allow-local-files  # PDF + 本地圖片
marp RFQ簡報.md --theme gaia               # 使用 gaia 主題
marp RFQ簡報.md --watch                    # 自動監看變更

# 批次轉換
marp rfq/*.md                      # 轉換所有 Markdown
```
