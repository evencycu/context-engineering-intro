# Teams Bot Platform Database Schema

## 概述

這是一個 Teams Bot 中台服務的資料庫設計，支援多個 Teams Bot 和第三方 Bot 的統一管理，提供跨多個 Teams Bot/Agents 的中台服務。

## 核心架構特色

### 🤖 多 Bot 支援
- **Platform Bots**: 中台統一管理的 Bot
- **Third Party Bots**: 第三方 Bot 註冊和管理
- **Bot 路由**: 智能路由和負載均衡
- **Bot 健康監控**: 即時健康狀態追蹤

### 🔗 統一 API 介面
- 提供統一 API 讓第三方 Bot 發送訊息
- 支援多種訊息格式 (文字、檔案、Adaptive Card)
- 完整的認證和權限管理
- 使用量追蹤和計費

### 📊 企業級功能
- 多租戶架構
- 完整的審計追蹤
- 使用量監控和計費
- 健康檢查和監控

## 資料表結構

### 核心平台表 (3 個)
1. `companies` - 公司管理
2. `users` - 用戶管理  
3. `projects` - 專案/通知金鑰管理

### Bot 管理表 (4 個)
4. `platform_bots` - 平台 Bot 管理
5. `third_party_bots` - 第三方 Bot 註冊
6. `bot_installations` - Bot 安裝記錄
7. `bot_routing_rules` - Bot 路由規則

### 目的地管理表 (1 個)
8. `destinations` - Teams 目的地管理

### 通知系統表 (2 個)
9. `notifications` - 通知訊息
10. `notification_destinations` - 通知-目的地關聯

### Bot 路由和監控表 (2 個)
11. `bot_health_status` - Bot 健康狀態
12. `third_party_bot_api_keys` - 第三方 Bot API 金鑰

### 計費系統表 (3 個)
13. `billing_plans` - 計費方案
14. `company_billing` - 公司計費設定
15. `usage_records` - 使用記錄

### 審計和配置表 (4 個)
16. `audit_logs` - 審計日誌
17. `system_logs` - 系統日誌
18. `system_settings` - 系統設定
19. `feature_flags` - 功能開關

## 核心功能

### 1. Bot 管理
- **平台 Bot**: 中台統一管理的 Bot，具備完整權限
- **第三方 Bot**: 外部 Bot 註冊，透過 API 金鑰管理
- **Bot 安裝**: 追蹤 Bot 在各 Teams 環境的安裝狀態
- **健康監控**: 即時監控 Bot 狀態和效能

### 2. 智能路由
- **路由規則**: 基於條件自動選擇最適合的 Bot
- **負載均衡**: 分散請求到多個 Bot
- **故障轉移**: 自動切換到健康的 Bot
- **效能優化**: 根據 Bot 效能動態調整路由

### 3. 統一 API
- **第三方整合**: 提供 API 讓外部系統發送訊息
- **多格式支援**: 文字、檔案、Adaptive Card
- **權限控制**: 基於 API 金鑰的權限管理
- **使用量追蹤**: 詳細的 API 使用記錄

### 4. 目的地管理
- **預先申請**: 目的地需要預先註冊和驗證
- **多 Bot 支援**: 同一個目的地可以透過不同 Bot 發送
- **驗證機制**: 確保目的地有效性和權限

### 5. 計費和監控
- **使用量追蹤**: 詳細記錄每個 Bot 的使用情況
- **計費計算**: 基於使用量和 Bot 類型的計費
- **效能監控**: Bot 回應時間和成功率監控
- **告警機制**: 異常情況自動告警
