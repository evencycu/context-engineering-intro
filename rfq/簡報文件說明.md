## 🚀 快速開始（3 步驟）

### Step 1: 安裝 Marp CLI

```bash
# 使用 npm
npm install -g @marp-team/marp-cli

# 或使用 Homebrew (macOS)
brew install marp-cli
```

### Step 2: 執行轉換腳本

```bash
cd rfq
./convert.sh
```

### Step 3: 選擇格式

```
請選擇轉換格式：
  1) PDF (建議用於正式簡報)
  2) HTML (建議用於線上展示)
  3) PPTX (建議用於進一步編輯)
  4) 全部格式
```

**就這麼簡單！** 🎉

## ❓ 常見問題

### Q1: 轉換失敗怎麼辦？

**A**: 檢查 Marp CLI 是否正確安裝

```bash
marp --version

# 若未安裝
npm install -g @marp-team/marp-cli
```

### Q2: 中文顯示異常？

**A**: 確保系統已安裝中文字體（macOS 預設已有）

### Q3: 需要修改內容怎麼辦？

**A**: 直接編輯 `RFQ簡報.md`，然後重新執行 `./convert.sh`

### Q4: 可以用其他工具嗎？

**A**: 可以！
- **VS Code + Marp 擴充套件**: 視覺化編輯
- **Marp Web**: https://web.marp.app/ (線上版)
- **Pandoc**: `pandoc -t beamer RFQ簡報.md -o output.pdf`

### Q5: 如何加入公司 Logo？

**A**: 編輯 `RFQ簡報.md`

```markdown
![width:200px](./images/company-logo.png)
```
